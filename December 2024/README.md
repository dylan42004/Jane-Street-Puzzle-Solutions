# December 2024 — Games Night!

## The puzzle
A chaotic image of game pieces from 11 different board games strewn across a table,
with Christmas flavor text but no explicit instructions — only the hint that the
answer is a single word.

[View the original puzzle](https://www.janestreet.com/puzzles/archive/)

## My approach
A two-layer visual-decoding puzzle:

**Layer 1 — find the instruction.** The visible pieces, grouped by which game they
came from, were each arranged into a letter. Reading those letters in the order the
game boxes were stacked at the top of the image spelled out **"MISSING ONES"** — a
two-word phrase pointing to the next step.

**Layer 2 — decode the missing pieces.** Following that instruction, I looked at what
each game was *missing*. Most games were short exactly one piece (the flavor text's
"only completed a couple of sets" hint). Ordered the same way as before:

| Game | Missing piece | Letter |
|------|---------------|--------|
| Uno | Yellow | Y |
| Catan | Ore | O |
| Risk | Ural | U |
| Monopoly | (complete) | (space) |
| Dominion | Silver | S |
| Scrabble | U tile | U |
| Sushi Go! | Nigiri | N |
| Chess | Kings | K |
| Clue | (complete) | (space) |
| Stratego | Miners | M |
| Bananagrams | Y tile | Y |

Taking the first letter of each missing piece — with the complete sets (Monopoly,
Clue) as spaces — spells **"YOU SUNK MY."**

**Completing the phrase.** "You sunk my ___" resolves to **"You sunk my battleship,"**
the tagline of the game Battleship — itself another board game, fitting the theme.

## Result
**Final answer: Battleship**
